\subsection{Fusion des données}

Je disposais de plusieurs fichiers contenant des informations sur les étudiants, notamment leurs noms, prénoms, dates de naissance, numéros d'étudiant, ainsi que leur parcours académique. Un autre fichier contenait également les résultats universitaires des étudiants. J'ai donc décidé de fusionner ces fichiers afin d'obtenir un seul fichier complet regroupant toutes les informations pertinentes.

Pour ce faire, j'ai d'abord identifié les colonnes communes entre les deux fichiers, principalement \texttt{"Numéro"} et \texttt{"Année Université"}. Ensuite, j'ai utilisé la fonction \texttt{merge()} de la bibliothèque \texttt{pandas} avec l'option \texttt{how="inner"} afin de ne conserver que les lignes présentes dans les deux fichiers, c'est-à-dire les étudiants pour lesquels les informations sont complètes.
Une fois la fusion effectuée, j'ai vérifié que le nombre de lignes du fichier résultant correspond bien à ce qui était attendu (intersection des deux jeux de données). Après m'être assuré que la fusion s'était déroulée correctement, j'ai exporté le fichier final sous le nom 
\texttt{"base\_finale.csv"} pour une utilisation ultérieure dans les analyses.
